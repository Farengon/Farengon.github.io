## 修复 GitHub Pages 构建错误（Liquid 语法）
- 报错原因：unit4 中 topic4-11/4-12/4-13 的 Java 二维数组初始化 `{{9, 8, 7}, ...}` 被 Jekyll Liquid 当作模板变量解析，导致 build 失败。
- 修复：所有含 `{{ }}` 的代码块外包 `{% raw %} ... {% endraw %}`；行内代码/选项文本用行内 raw 标签包裹。三个文件 raw/endraw 标签均已配对。
- 附带修复：unit2/index.md 的 title 改为 "Unit 2"（原含全角冒号，与子页面 `parent: Unit 2` 不匹配，just-the-docs 导航会失效）。
- 经验：Jekyll 中 Markdown 内容里的 `{{`、`{%` 必须用 raw 标签转义，Java/JS 代码块含花括号时尤其要注意；子页面 parent 必须与父页面 title 完全一致。
