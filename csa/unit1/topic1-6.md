# 1.6 Compound Assignment Operators

## 1.6.A

**Develop code for assignment statements with compound assignment operators and determine the value that is stored in the variable as a result.**

### 1.6.A.1 Compound Assignment Operators 复合赋值运算符

{: .syntax}
| 运算符 | 描述 | 等价形式 |
|--------|------|----------|
| `+=` | 加后赋值 | `a += b` → `a = a + b` |
| `-=` | 减后赋值 | `a -= b` → `a = a - b` |
| `*=` | 乘后赋值 | `a *= b` → `a = a * b` |
| `/=` | 除后赋值 | `a /= b` → `a = a / b` |
| `%=` | 取模后赋值 | `a %= b` → `a = a % b` |

### 1.6.A.2 Post-increment and Post-decrement Operators 自增和自减

{: .syntax}
| 运算符 | 描述 | 等价形式 |
|--------|------|----------|
| `++` | 自增 1 | `a++` → `a = a + 1` |
| `--` | 自减 1 | `a--` → `a = a - 1` |
